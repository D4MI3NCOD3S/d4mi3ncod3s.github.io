Hybrid Search + RAG · AI 품질 평가 체계

Problem

"임산부가 먹어도 되는 진통제" 같은 자연어 질의에 키워드 완전일치 검색은 속수무책이었습니다. 의약품 도메인에서 오답은 곧 위험이라 일반 LLM 챗봇을 그대로 붙일 수 없었습니다.

Approach

여러 소스를 가중 결합하는 하이브리드 검색 위에 RAG를 얹고, 답변은 검색 결과와 대조해 걸렀습니다. 튜닝은 하나 고치면 다른 데가 깨지기 때문에 품질 자체를 CI 회귀 테스트로 만들었습니다.

BEFORE

  • 키워드 완전일치 검색
  • 자연어 · 의도 기반 질의 대응 불가
  • 환각 통제 없음
  • AI 품질은 주관적 확인
→원인 단위 튜닝회귀 평가

AFTER

  • 4소스 Hybrid Search 질의 유형별 동적 가중치
  • RAG + Agentic RAG 7종 도구 · 최대 6턴
  • Hallucination Guard + 결정적 금기 규칙
  • 골든셋 + CI 평가 워크플로우 3종 자동 실행

기술적 의사결정 · Trade-off

인기도 소스에 유사도 하한

"혈압약" 검색에 무관한 인기약이 섞이던 원인. 하한을 추가하고 자연어 질의에서는 인기도 가중치를 낮춤.

토큰별 UNION

"아스피린과 타이레놀"에서 인기약이 슬롯을 독점 → 약품마다 공정하게 슬롯 배정.

효능 텍스트 사전 추출

JSONB 추출 + 9만 행 seq scan이 병목 → 컬럼으로 미리 뽑고 인덱스 분리. 11.7s → 0.46s (EXPLAIN 기준)

모델 티어링 + 서킷브레이커

요약은 빠른 티어로 1차 처리하고 폴백을 둠. 응답 없는 모델은 끊음. 24s → 8s

숨기지 않고 알린다

AI 판단으로 결과를 감추던 로직을 "관련도 낮음" 표시로 전환.
